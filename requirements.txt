# AU Meter Cupboard Scheduling System
#
# 唯一权威依赖清单。从仓库根目录安装：
#     pip install -r requirements.txt
#
# backend/requirements.txt 指向本文件，不再重复维护。
#
# 最低要求：Python 3.11+（本项目使用了 `X | None` 联合类型语法与
# `list[str]` 泛型下标，Python 3.9 及以下无法解析）。
#
# ---- 关于 pdfplumber（重要）----
# 报告第 08 章把 pdfplumber 列为 PDF 解析库，但实测**全库零引用** ——
# STAGE 1 的 PDF 坐标提取全部走 PyMuPDF（import fitz）。
#
# 之所以从主清单移出：pdfplumber 会传递依赖 pypdfium2，而 pypdfium2
# 在 **macOS 11+ Intel** 上没有预编译 wheel，必须源码编译；其构建脚本
# 要从 GitHub 下载 pdfium 二进制，在 macOS 11 上会因SSL 证书链过期而
# 失败（`CERTIFICATE_VERIFY_FAILED`），导致**整个 pip 安装回滚**，
# 连 uvicorn 都装不上。
#
# 需要它时再装（会附带 pypdfium2）：
#     pip install pdfplumber==0.11.9
# 当前阶段不需要，解析功能不受任何影响。
